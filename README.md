Descrição do Projeto – AgroForte Sustentável

O projeto **AgroForte Sustentável** foi desenvolvido com o objetivo de conscientizar sobre a importância da sustentabilidade no meio agrícola, destacando práticas responsáveis que contribuem para a preservação ambiental e para a produção de alimentos de forma equilibrada.

O site apresenta informações sobre ações sustentáveis no campo, como economia de água, agricultura orgânica, utilização de energias renováveis e preservação da biodiversidade. Além disso, conta com uma galeria de imagens ilustrativas que reforçam visualmente os conceitos abordados.

Para o desenvolvimento do projeto foram utilizadas as tecnologias **HTML5**, **CSS3** e **JavaScript**, permitindo a criação de uma interface moderna, responsiva e interativa. Entre os recursos implementados está o sistema de alternância entre tema claro e escuro, proporcionando uma melhor experiência de navegação ao usuário.

As imagens utilizadas no projeto foram obtidas do banco de imagens gratuito **Unsplash**, respeitando as condições de uso da plataforma. Também foram utilizadas fontes do sistema (Arial, Helvetica e Sans-Serif), amplamente compatíveis com navegadores modernos, garantindo boa legibilidade e desempenho.
Também foi utilizada a IA para customizar alguns códigos.

O projeto busca demonstrar como a tecnologia pode ser utilizada para divulgar informações sobre sustentabilidade, incentivando práticas agrícolas mais conscientes e alinhadas à preservação do meio ambiente.
